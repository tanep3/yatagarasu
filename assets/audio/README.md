- 話者: VOICEVOX 青山龍星
- クレジット: `VOICEVOX:青山龍星`
- SHA-256: `5039cd6f77dd7d57db65edefac5b2f56356f4f4a3c04a6ef9d42fd16c2d13257`
- 形式: MP3、8kHz、mono、約1.01秒

## `wake_prompt_hai.wav`

ウェイク応答の体感遅延を減らすため、上記MP3の先頭・末尾無音を除いて
PCM WAVへ変換した実行用音声です。標準設定ではこちらを再生します。

- クレジット: `VOICEVOX:青山龍星`
- SHA-256: `098ecc8053a169d61f33742f9603f516e1928a444b71acf6d5b2759e1e0ac0e1`
- 形式: PCM signed 16-bit little-endian、8kHz、mono、約0.28秒

利用・再配布時は、VOICEVOXおよび青山龍星の最新規約を確認し、
上記クレジットを表示してください。

- [VOICEVOX 音声モデル利用規約](https://github.com/VOICEVOX/voicevox_vvm/blob/main/TERMS.txt)
